## Décisions prises en session

**PyMySQL `%%` escaping** : les chaînes SQL Python avec `CONCAT('%#', c.id, '#%')` doivent utiliser `%%` pour produire `%` littéral au niveau PyMySQL. Sans double-escape, PyMySQL interprète `%#` comme un placeholder et lève `ProgrammingError`.

**Qualification `scenario.id` dans la sous-requête EXISTS** : la requête de `called_while_inactive` utilise `CAST(scenario.id AS CHAR)` avec le préfixe de table explicite. Sans qualification, MariaDB résout `id` sur `scenarioExpression` (table de la sous-requête), ce qui produit une auto-jointure silencieuse et un résultat faux.

**`has_warning` : ajout conditionnel de `status` au SELECT** : la colonne `status` n'est sélectionnée que lorsque `has_warning=True`, pour ne pas modifier la structure de retour des appels existants.

**`generic_type_missing` : `type='info'` forcé uniquement si `cmd_type` non spécifié** : évite un conflit de condition si l'appelant a déjà filtré sur `type='action'`.
